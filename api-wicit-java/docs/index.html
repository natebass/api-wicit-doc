WICit Documentation

Developer documentation for WICit, the site that helps Californians find where to shop with WIC.

  • PrerequisitesTools to install before working on either project.
  • Backend setupThe Spring Boot API in api-wicit-java.
  • DeploymentRun the API on EC2 behind HTTPS.
  • Frontend setupThe Vite+ website in wicit.
  • Published dataThe CDPH WIC datasets and how they are stored in the database.
  • API referenceJavadoc generated from the API source.

Repository layout

This repository holds both applications. Run commands from the repository root with make, and open each application folder in its own IDE window.

Path What it is
Makefile Commands to run, build and test both applications. Run make to list them.
api-wicit-java/ The backend API: Java, Spring Boot and Gradle.
api-wicit-java/docs/ The source of this site.
wicit/ The frontend website: JavaScript, Vite+ and pnpm.

Quick start

git clone https://github.com/natebass/api-wicit-doc.git
cd api-wicit-doc
make backend     # start the API
make frontend    # start the website at http://localhost:5173
