Prerequisites

Install these tools before working on WICit. Both projects support Windows, macOS and Linux.

Requirements

Tool Version Needed for
Git Any recent Both
GNU Make 4.x Running the root make commands
JDK 27 Backend
Gradle 9.8.1, via the included wrapper Backend (no separate install)
Node.js 24 Frontend
Vite+ (vp) Latest Frontend
pnpm The version in wicit/package.json Frontend (downloaded automatically)

Git

Install Git from git-scm.com, then clone the repository:

git clone https://github.com/natebass/api-wicit-doc.git

GNU Make

The root Makefile wraps the commands for both projects. Make is optional: every target is a short command you can also run by hand from the project folder.

Windows

choco install make

On Windows the Makefile runs every command in cmd.exe, so it works from PowerShell, Command Prompt or Git Bash.

macOS

xcode-select --install

Linux (Debian/Ubuntu)

sudo apt install make

JDK 27

The backend compiles with a Gradle Java toolchain set to version 27. Install any JDK 27 distribution, such as Eclipse Temurin, and check it:

java -version

You don't need to install Gradle. The gradlew and gradlew.bat wrappers download the correct version the first time they run.

Node.js and Vite+

The frontend is built with Vite+, which provides the vp command. Install Node.js 24 from nodejs.org, then follow the Vite+ install guide. Check both:

node --version
vp --version

pnpm is pinned in devEngines in wicit/package.json and is downloaded automatically when it is missing.

IDEs

Open each application folder as its own project, not the repository root:

  • api-wicit-java in IntelliJ IDEA or another Gradle-aware Java IDE.
  • wicit in VS Code. The folder includes recommended extensions in .vscode/extensions.json.
