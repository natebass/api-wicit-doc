Backend setup

The WICit API is a Spring Boot application in api-wicit-java, built with Gradle.

Requirements

ComponentVersion
Java (toolchain)27
Gradle (wrapper)9.8.1
Spring Boot4.1.1
Spring dependency management plugin1.1.7
TestsJUnit Platform via spring-boot-starter-test

See Prerequisites to install the JDK.

Project layout

PathWhat it is
build.gradlePlugins, Java toolchain, dependencies and the docs site task.
src/main/java/org/opensac/wicitapi/Application source. Application is the entry point.
src/main/resources/application.propertiesSpring configuration. The application name is wicit-api.
src/test/java/Tests.
docs/Source pages for this documentation site.

Configuration

Sensitive settings for the API go in a .env file at the repository root. It is ignored by Git, so never commit it. Ask a maintainer for the values.

Run, build and test

From the repository root:

CommandWhat it does
make backendRuns the API with bootRun.
make backend-buildCompiles and packages the API, skipping tests.
make backend-testRuns the tests.
make backend-cleanDeletes the build/ folder.
make docsBuilds this site with the Javadoc into api-wicit-java/build/site.

Without Make, run Gradle from api-wicit-java. Use gradlew.bat on Windows and ./gradlew on macOS and Linux:

cd api-wicit-java
./gradlew bootRun
./gradlew test
./gradlew docsSite

Documentation site

The docsSite Gradle task generates the Javadoc and copies it to build/site/api, next to the pages from docs/. Open build/site/index.html in a browser to preview the site.

On every push to master that changes api-wicit-java/, the Deploy docs to GitHub Pages workflow builds the site and publishes it to natebass.github.io/api-wicit-doc.

Write Javadoc comments on public classes and methods. They appear in the API reference.
