Frontend setup

The WICit website is in wicit. It is built with Vite+ and uses pnpm to manage packages.

Requirements

ComponentVersion
Node.js24
Vite+ (vp)Pinned in pnpm-workspace.yaml under catalog
pnpmPinned in devEngines in package.json
Bootstrapv6 development build from GitHub
Leaflet1.9.4
Sass1.x

See Prerequisites to install Node.js and Vite+.

Configuration

Copy the template to create your local environment file:

cd wicit
cp .env.dist .env
VariablePurpose
VITE_MAPBOX_INTEGRATION_URLMapbox raster tile URL for the map. Required. Set it in .env only, never in .env.dist.
VITE_LOCATIONS_API_URLCalifornia WIC vendor locations API (CHHS datastore SQL). The template sets a default.
VITE_LOCATIONS_RESOURCE_IDCHHS dataset ID for vendor locations. The template sets a default.

Get a Mapbox URL

  1. Go to Mapbox Studio and click New style.
  2. Select Classic styles → Streets, then click Customize.
  3. Click Share. Under Production URL, copy the Preview only URL.
  4. Paste it as VITE_MAPBOX_INTEGRATION_URL in .env.

Every VITE_ variable ends up in the public browser bundle. Restrict the Mapbox token to your URLs in Mapbox's settings.

Run, build and test

From the repository root:

CommandWhat it does
make frontendInstalls packages and starts the dev server at localhost:5173.
make frontend-installInstalls packages.
make frontend-buildBuilds the production site into wicit/dist.
make frontend-previewBuilds, then serves the production build.
make frontend-testRuns the Vitest tests once.

Without Make, run Vite+ from wicit:

cd wicit
pnpm install
vp dev
vp test
vp check
vp build

Translations

Every string is rendered through a message catalog. English, in src/js/i18n/locales/en.json, is the source of truth. Other languages fall back to English key by key. To add a language, add it to src/js/i18n/locales.js with a matching JSON catalog. See src/js/i18n/locales/README.md for details.
