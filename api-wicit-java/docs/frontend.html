Frontend setup

The WICit website is in wicit. It is built with Vite+ and uses pnpm to manage packages.

Requirements

Component Version
Node.js 24
Vite+ (vp) Pinned in pnpm-workspace.yaml under catalog
pnpm Pinned in devEngines in package.json
Bootstrap v6 development build from GitHub
Leaflet 1.9.4
Sass 1.x

See Prerequisites to install Node.js and Vite+.

Project layout

Path What it is
index.html The page Vite serves and builds.
src/main.js Entry script.
src/js/ Application code, including lib/config.js and i18n/.
src/scss/ Styles.
public/ Static files copied as is.
tests/ Vitest tests.

.env.dist Template for .env.

Configuration

Copy the template to create your local environment file:

cd wicit
cp .env.dist .env
Variable Purpose
VITE_MAPBOX_INTEGRATION_URL Mapbox raster tile URL for the map. Required. Set it in .env only, never in .env.dist.
VITE_API_BASE_URL Base URL of the WICit API, which serves the map's vendors and the food search. The template sets http://localhost:8080, where make backend runs it.

The map and the food search need the API running. Start it with make backend in a second terminal; see Backend setup.

The Deploy to GitHub Pages workflow reads VITE_MAPBOX_INTEGRATION_URL and VITE_API_BASE_URL from the repository's Actions variables. In a fork, set both under Settings → Secrets and variables → Actions → Variables. VITE_API_BASE_URL must be an https:// URL, because browsers block requests from an HTTPS page to an HTTP API.

Get a Mapbox URL

  1. Go to Mapbox Studio and click New style.
  2. Select Classic styles → Streets, then click Customize.
  3. Click Share. Under Production URL, copy the Preview only URL.
  4. Paste it as VITE_MAPBOX_INTEGRATION_URL in .env.

Every VITE_ variable ends up in the public browser bundle. Restrict the Mapbox token to your URLs in Mapbox's settings.

Run, build and test

From the repository root:

Command What it does
make frontend Installs packages and starts the dev server at localhost:5173.
make frontend-install Installs packages.
make frontend-build Builds the production site into wicit/dist.
make frontend-preview Builds, then serves the production build.
make frontend-test Runs the Vitest tests once.

Without Make, run Vite+ from wicit:

cd wicit
pnpm install
vp dev
vp test
vp check
vp build

Translations

Every string is rendered through a message catalog. English, in src/js/i18n/locales/en.json, is the source of truth. Other languages fall back to English key by key. To add a language, add it to src/js/i18n/locales.js with a matching JSON catalog. See src/js/i18n/locales/README.md for details.
