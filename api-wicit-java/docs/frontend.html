Frontend setup

The WICit website is a vanilla JS Vite+ single-page application.

Requirements

See Prerequisites to install Node.js and Vite+.

Configuration

Copy the template to create your local environment file:

cd wicit
cp .env.dist .env
Variable Purpose
VITE_MAPBOX_INTEGRATION_URL Mapbox raster tile URL for the map.
VITE_API_BASE_URL Use https://api.findwic.com for production and http://localhost:8080 for development.

The map and the food search need the API running. Start it with make backend in a second terminal; see Backend setup.

The Deploy to GitHub Pages workflow reads VITE_MAPBOX_INTEGRATION_URL and VITE_API_BASE_URL from the repository's Actions variables. In a fork, set both under Settings → Secrets and variables → Actions → Variables. VITE_API_BASE_URL must be an https:// URL, because browsers block requests from an HTTPS page to an HTTP API.

Get a Mapbox URL

  1. Go to Mapbox Studio and click New style.
  2. Select Classic styles → Streets, then click Customize.
  3. Click Share. Under Production URL, copy the Preview only URL.
  4. Paste it as VITE_MAPBOX_INTEGRATION_URL in .env.

Every VITE_ variable ends up in the public browser bundle. Restrict the Mapbox token to your URLs in Mapbox's settings.

Translations

Message catalogs

Every catalog is a flat JSON object mapping a message key to the string shown to the reader. `en.json` is the source of truth; the runtime falls back to it **per key**, so a catalog that is empty, partial, or mid-review always renders — translated where a key exists, English everywhere else.

Supported languages:
  • English
  • Spanish
  • Simplified Chinese

Translating

  1. Copy the keys you are translating out of `en.json` into the target catalog.
  2. Translate the values, leaving `{placeholder}` tokens exactly as written — the runtime substitutes them, and a renamed token is rendered literally so the mistake is visible.
  3. Keep any HTML in a value intact. Markup inside a message is trusted and rendered as-is; only placeholder values are escaped. Do not add markup that was not in the English string.
  4. Leave out keys you have not translated. Do **not** ship a key with an empty string — an empty value counts as a translation and hides the English fallback.

Plurals

Keys ending in a CLDR plural category (`.one`, `.other`, and where a language needs them `.zero`, `.two`, `.few`, `.many`) are selected at runtime by `tCount()` from the count. Provide whichever categories the language actually uses; `.other` is required as the fallback form.

Adding a language

Add an entry to `../locales.js` and a `.json` file here. Nothing else needs to change — the switcher, the ``/`dir` attributes, and number formatting all read that registry.

Every string is rendered through a message catalog. English, in src/js/i18n/locales/en.json, is the source of truth. Other languages fall back to English key by key. To add a language, add it to src/js/i18n/locales.js with a matching JSON catalog. See src/js/i18n/locales/README.md for details.
